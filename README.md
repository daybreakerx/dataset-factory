# Dataset Factory

面向 LoRA 训练数据集的**打标流水线工具**：把预先切好、归好类的图片 / 视频素材，打成能直接送训练的描述（caption），最终整理成目标模型要的格式。

## 核心功能

- **聊天打标（Web / CLI 对等）**：发一张图或一段视频 + 一句指令，模型输出 caption，回复流式呈现——等待时能看出「在动」还是「卡住」；多轮对话式迭代改写；会话自动落盘、重启可恢复。
- **流式与思考过程**：思考型模型的思考内容单列成可折叠区，生成结束后可展开回看；思考只用于呈现，不进产物。
- **视频输入**：图片与视频都可作为素材（单轮一个附件）；视频自动抽帧、抽帧参数可调；模型不支持视频时给分类错误提示。
- **策略工作台**：左侧编辑基础提示词、右侧用图 / 视频调试对话；试标满意后把「提示词 + 端点 + Skill」的组合存进策略库，跨目录、跨批次复用；有未保存修改时锁定切换，避免丢失。
- **批量打标**：以工作目录为单位批量打标，一个目录可建多个批次；每个批次持有独立的策略快照，改库策略不影响已建批次。失败可重试，停止在当前条目收尾后生效、已完成产物保留；素材缺失可按记录的来源自动补回。
- **对照与复盘**：同一素材可对照它在其他批次的结果；每轮实际发出的完整请求先落盘再调模型，失败也有「当时喂了什么」可查。
- **提示词库**：打标必选的基础提示词集中管理、随时切换；旧版自动滚动备份。
- **Skill 扩展**：导入 agentskills.io 标准的 Skill 包（选择或拖入文件夹均可），打标时按需启用；包内容可在界面查看与修改。
- **多端点接入**：多套 OpenAI 兼容 API 端点（「名称 + 地址 + 模型 + 密钥」）并存、一键切换当前使用；每套可带高级参数（模型参数与超时重试）；支持连通性测试。
- **导出交付**：导出前预览入包清单、可排除个别条目；ZIP 内素材与 caption 同名配对、平铺即用，解压后可直接指定为训练器的数据目录。
- **服务管理**：界面常驻显示服务状态；设置页可看运行日志；电源按钮确认后安全关闭后台服务。

## 界面

Web 端支持跟随系统、亮色、暗色三种主题，侧栏可折叠。页面为「策略」工作台、「打标」与「设置」（端点配置、技能、服务运行）；界面会记住上次停留的页面与关键选择。
