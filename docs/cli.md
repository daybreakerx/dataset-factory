# CLI 命令行手册

`dsf` 是 Dataset Factory 的命令行入口，与 Web 界面共享同一套后端能力：配置端点、打标、跑批、导出，Web 里能做的事命令行都能做。它的输出适合管道处理，既可以手动单条执行，也方便写进脚本或交给外部 Agent 编排。

## 运行方式

在仓库内无需安装，直接用 uv 运行（推荐，始终与当前代码同步）：

```bash
cd backend
uv run dsf --help
```

也可以全局安装后使用 `dsf`（安装为 uv tool，代码以可编辑方式链接，改动即时生效）：

```bash
uv tool install ./backend
dsf --help
```

工作数据默认保存在 `~/.dataset_factory/`，可用环境变量 `DATASET_FACTORY_HOME` 改位置。

## 快速示例

单张图片打标（`-i` 指定图片，`-m` 是指令，`--endpoint` 用端点 ID 或唯一显示名）：

```bash
dsf label -i photo.jpg -m "写一段用于 LoRA 训练的画面描述" --endpoint my-endpoint
```

视频打标（`--video` 与 `--image` 互斥，可控制抽帧密度）：

```bash
dsf label --video clip.mp4 --video-fps 1 --video-max-frames 12 -m "描述整个片段" --endpoint my-endpoint
```

终端多轮对话，附图/附视频用 `@文件路径 指令` 的形式，Ctrl-D 或 Ctrl-C 退出：

```bash
dsf chat
```

前台执行某个工作目录下的批次（Ctrl-C 会等待当前条目安全收尾并输出中断报告）：

```bash
dsf run <工作目录> <批次>
```

启动本地 Web 服务（默认 http://127.0.0.1:8000）：

```bash
dsf serve
```

任意命令加 `--help` 可以查看它的全部参数。

## 命令总览

顶层命令：

| 命令 | 用途 |
| --- | --- |
| `dsf label` | 单发打标：图片或视频 + 指令，输出 caption |
| `dsf chat` | 终端多轮打标（交互式） |
| `dsf run` | 前台执行批次无人值守打标 |
| `dsf serve` | 启动本地 Web 服务（HTTP API + 界面） |

命令组：

| 命令组 | 管什么 |
| --- | --- |
| `dsf config` | 端点配置（base_url / 模型名 / API 密钥，支持多套） |
| `dsf prompt` | 提示词库（增删改查） |
| `dsf skill` | Skill 包（agentskills.io 标准） |
| `dsf strategy` | 策略库（端点 + 提示词 + Skill 的组合） |
| `dsf workdir` | 工作目录登记、导入、迁移与维护 |
| `dsf batch` | 批次管理与条目状态 |
| `dsf export` | 数据集打包导出 |
| `dsf session` | 对话会话管理 |

## 常用选项

`dsf label` / `dsf chat` 的选择项：

| 选项 | 作用 |
| --- | --- |
| `--endpoint` | 端点配置（ID 或唯一显示名） |
| `-p, --prompt` | 基础提示词（ID 或唯一显示名） |
| `-s, --skill` | 启用的 Skill（ID 或唯一显示名） |
| `--session` | 续接已有会话（续接即迭代改写） |
| `-i, --image` | 图片文件路径（仅 `label`） |
| `-v, --video` | 视频文件路径，与 `--image` 互斥（仅 `label`） |
| `--video-fps` | 视频抽帧 fps（1–10） |
| `--video-max-frames` | 视频抽帧帧数上限 |
| `-m, --message` | 打标指令（仅 `label`；纯图轮可省） |

`dsf run` 的选项：

| 选项 | 作用 |
| --- | --- |
| `--mode full\|retry` | 全量跑或只跑重试列表，默认 `full` |
| `--yes` | 确认跳过未导入文件、继续本次跑批（脚本场景必给） |

`dsf serve` 的选项：`--host`（默认 127.0.0.1）、`--port`（默认 8000）、`--log-level`（DEBUG/INFO/WARNING/ERROR）。

## 命令组详解

### `dsf config` —— 端点配置

| 子命令 | 用途 |
| --- | --- |
| `add` | 新增一套端点配置；API 密钥交互输入（留空跳过，之后可用 `set` 补配） |
| `list` | 列出全部端点配置（密钥只报有无） |
| `show` | 查看指定配置（密钥只显示来源，绝不显示内容） |
| `set` | 更新指定配置的端点字段（密钥留空则沿用已存值） |
| `remove` | 删除一套端点配置（连同其密钥文件） |
| `test` | 测试端点连通性：发一个极小的真实请求（15 秒超时、max_tokens=1），不必先改配置 |
| `params` | 查看或设置端点的请求参数（生成参数 + 传输参数，与 Web 设置页「高级参数」同一份配置） |

### `dsf prompt` —— 提示词库

| 子命令 | 用途 |
| --- | --- |
| `list` | 列出提示词 |
| `show` | 查看提示词内容 |
| `save` | 保存（新建或覆盖）提示词 |
| `rename` | 重命名提示词 |
| `rm` | 删除提示词 |

### `dsf skill` —— Skill 包

| 子命令 | 用途 |
| --- | --- |
| `import` | 从文件夹导入 Skill 包 |
| `list` | 列出已导入 Skill 及启停状态 |
| `enable` / `disable` | 启用 / 停用 Skill |
| `files` | 查看 Skill 包内文件清单 |
| `read` | 读取 Skill 包内文件内容 |
| `rename` | 重命名 Skill |
| `rm` | 删除 Skill |

### `dsf strategy` —— 策略库

策略是「端点 + 提示词 + Skill」的一份组合清单，引用的内容必须已存在（参数为 ID 或唯一显示名）。

| 子命令 | 用途 |
| --- | --- |
| `add` | 保存一份组合 |
| `list` | 列出策略和实时引用健康度（失效策略仍可见） |
| `show` | 按稳定 ID 查看策略 |
| `use` | 查看或设置「当前使用策略」——`dsf label` / `dsf chat` 缺省时的组合来源 |
| `edit` | 只修改明确提供的字段；已有批次的策略快照保持不变 |
| `copy` | 复制一份策略，分配新 ID |
| `rm` | 删除库策略；已经应用的批次仍可使用快照 |
| `rebind` | 重新指定缺失引用，未指定的引用保持原样 |

### `dsf workdir` —— 工作目录

| 子命令 | 用途 |
| --- | --- |
| `add` | 登记并导入素材；不传来源时就地采用目录内素材 |
| `list` | 列出已登记工作目录 |
| `show` | 显示目录登记、导入记录和迁移待处理状态 |
| `import` | 增量复制导入或就地补登记，按内容判定重复与冲突 |
| `reimport` | 从已记录来源恢复缺失素材；省略名称则恢复全部可找回素材 |
| `relocate` | 复制并校验后迁移，完整成功后清理旧位置 |
| `cleanup-old` | 重试清理迁移记录证明的旧位置 |
| `verify` | 按活跃批次校验当前素材与打标时哈希，同时列出孤立产物 |
| `rebuild-imports` | 以现状重建导入集合，来源记空，旧历史保留 |
| `cleanup` | 列出或清理明确选择的孤立产物（默认不选择任何文件） |
| `cleanup-runs` | 列出或清理所选运行记录（清理会丢失打标时哈希与失败原因） |
| `rm` | 删除整个工作目录；交互两次确认，脚本必须显式提供 `--yes` |

### `dsf batch` —— 批次

| 子命令 | 用途 |
| --- | --- |
| `add` | 从库复制策略或从零配置新批次；脚本须显式给出名称、端点与提示词 |
| `list` | 列出目录全部批次，包括已隐藏批次 |
| `show` | 查看批次元数据、产物数量与自包含策略快照 |
| `edit` | 修改批次显示名称与描述 |
| `items` | 查看六组条目（已完成、未完成、重试、缺失、未导入等），支持按分组与文件名过滤 |
| `status` | 读取指定批次的实时运行状态，覆盖 CLI 与 Web 发起的运行 |
| `stop` | 请求当前批次协作停止，等待当前条目安全收尾 |
| `retry` | 查看 / 处理重试列表 |
| `exclude` | 排除指定条目的打包资格，或撤销此前排除 |
| `hide` / `unhide` | 隐藏批次 / 重新显示（正在运行的批次隐藏时会先安全收尾） |
| `rm` | 删除批次与配对产物，保留素材和运行历史 |

### `dsf export` —— 导出

| 子命令 | 用途 |
| --- | --- |
| `plan` | 查看将入包清单与被排除清单（默认按导入顺序从 001 编号） |
| `run` | 按当前配对状态导出平铺 ZIP（图片 + 同名 `.txt` + `.caption` 双格式），不覆盖已有文件 |

### `dsf session` —— 会话

| 子命令 | 用途 |
| --- | --- |
| `list` | 列出对话会话 |
| `show` | 查看会话内容 |
| `remove` | 删除会话 |

## 退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 运行失败或用户中止 |
| `2` | 命令用法错误（参数缺失 / 拼错、非交互缺少 `--yes`） |
| `130` | 被 Ctrl-C 打断 |
